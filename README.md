# 🚀 InvoiceIQ – AI Invoice Auditor

## 📌 Overview

InvoiceIQ is an AI-powered invoice auditing system designed to automate the validation and processing of invoices. It helps in detecting inconsistencies, validating data, and improving accuracy in financial workflows.

---

## ✨ Features

* 📄 Automated invoice data extraction
* 🤖 AI-based validation and anomaly detection
* 📊 Structured data processing pipeline
* ⚡ Fast and efficient processing
* 🧩 Modular architecture for scalability

## ⚙️ Installation

### 1️⃣ Clone the repository

```
git clone https://github.com/MAITREY30/invoiceiq-branding.git
cd invoiceiq-branding
```

### 2️⃣ Create virtual environment

```
python -m venv venv
source venv/bin/activate   # Linux/Mac  
venv\Scripts\activate      # Windows  
```

### 3️⃣ Install dependencies

```
pip install -r requirement.txt
```

---

## ▶️ Run the Application

```
python app.py
```
